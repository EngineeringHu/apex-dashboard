# 双击加密 / 解密

需要 Node.js 20 或以上版本，无需启动 Obsidian。

- 双击“解密周记.bat”：选择 .apexenc，选择库外的 Markdown 保存位置，在黑色窗口输入密码并回车。密码不回显。正文及附件一起导出，原密文保留。
- 双击“加密周记.bat”：选择 .md，选择 .apexenc 保存位置。当前笔记库已设置统一密码时自动沿用，无需再输入；没有统一配置时要求设置并确认至少 3 个字符的密码。

加密脚本生成副本，**原 .md 和原附件仍是明文，不会被删除**。若要将周记文件夹整体转换并清除原明文，请用 Obsidian 设置中的“周记加密”开关。

两种操作都拒绝覆盖已有文件。加密支持本地图片和文件附件，会保存到密文旁的 _assets；无法找到、同名含糊或不支持的嵌入内容会报错，不会悄悄遗漏。远程图片及嵌入 Markdown 笔记需要先整理为本地附件或正文。

移动密文时请带上 _assets 文件夹。移动这些工具时建议复制整个 tools 文件夹；若希望独立加密继续沿用笔记库密码，保留 tools 上一级的 .apex-weekly-keyring.json。不要把密码写入 .bat 或命令行参数。

独立加密不是全局开关，也不会修改 Obsidian 的密码配置。

BAT 使用 -ExecutionPolicy Bypass 仅放行它启动的 PowerShell 进程，退出后失效；不会执行 Set-ExecutionPolicy，也不会修改系统或用户的永久执行策略。
