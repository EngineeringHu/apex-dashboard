# 周计划表中的待办事项卡片

## 插入与编辑

- 空白任务单元格显示「+ 插入待办事项卡片」。其他单元格可通过右键菜单插入。
- 每个单元格可放置一张标准 Apex 待办事项卡片；双击标题或任务文字可编辑，输入任务后按 Enter 添加。
- 已有任务单元格通过右键插入卡片时，原文字和任务完成状态会转换到卡片中。
- 卡片支持原有的完成勾选、进度、提醒、子任务和折叠。横向、纵向合并单元格继续生效。

## 完成、延迟与作废

点击任务左侧的状态图标，可选择「完成」「延迟」「作废」。打开或关闭菜单本身不会修改任务，选中操作后才保存。普通待办卡片和周计划表内卡片使用同一交互；键盘聚焦图标后也可打开菜单。

- **完成**：显示勾选与删除线，计入完成进度。完成父任务会同时完成未作废的子任务，已作废子任务保持作废。
- **延迟**：显示时钟图标，仍是未完成任务，保留待办强调和历史待办记录。仅标记当前任务的状态，不自动移动到其他日期，不修改提醒时间或子任务状态；如需改提醒时间，仍使用原提醒入口。
- **作废**：显示作废图标、删除线和虚线边框，保留任务内容；不计入完成进度，也不进入日历、聚合待办或提醒；历史未完成计划保留作废任务，可用状态筛选隐藏。作废父任务会同时作废尚未结束的子任务，已完成子任务保留完成状态。单独作废的任务不会被「归档已完成」删除。
- **恢复未完成**：已完成、延迟和作废任务可再次点击状态图标恢复。恢复父任务会恢复其整棵任务树；恢复子任务会重新计算父任务状态，避免未完成子任务藏在作废父任务下。

所有状态变更同步到当前表格的关联副本。子任务全部结束时自动更新父任务：全部作废则父任务作废，完成与作废混合则父任务完成。进度计算排除作废任务，全为作废时显示 0%，不把作废当成完成。

完成继续保存为 `- [x]`，作废保存为 `- [-]`；延迟保存为 `- [ ]` 并附带 `<!--apex-task-status:deferred-->`。这些标记兼容任务类型、日记、提醒、折叠和关联元数据，并随加密周记一起保存。普通任务查询可用 `status = "deferred"` 筛选延迟任务；可用 `status = "cancelled"` 查询作废记录，恢复仍在原卡片操作。

状态规则位于独立的 `src/task-status.ts`，菜单适配位于 `src/task-status-ui.ts`，复用原同步与加密保存通道。回归命令 `npm run test:task-status` 覆盖状态转换、父子关系、关联同步、恢复、进度、扫描与归档，以及加密往返。

## 任务类型与样式

任务分为「计划任务」和「临时任务」。任务文字右侧用日历图标表示计划任务、闪电图标表示临时任务，不常驻显示类型文字。悬停可查看完整类型名称，点击图标切换；也可通过键盘聚焦后按 Enter 或空格打开菜单。子任务可单独设置。旧任务及新建任务默认按计划任务显示，只有显式设置类型时才保存类型标记，不会批量改写旧任务。关联副本同步修改类型，解除关联后可独立设置。

周计划表上方的「任务样式」打开设置窗口，适用于本笔记库所有周计划表中的待办卡片（包括未放置的卡片）。可开关未完成强调、类型配色和关联配色，并调整未完成色、计划色、临时色及关联组配色盘。窗口提供合成任务实时预览；保存后生效，取消不改变设置，「恢复默认」也需保存后才生效。

| 显示部分 | 规则 |
| --- | --- |
| 已完成任务 | 正文淡化并加删除线，取消任务底色及未完成强调线；保留类型图标和关联标识 |
| 未完成任务底色 | 关联组颜色优先，其次任务类型颜色，再其次未完成颜色，均关闭时使用主题默认 |
| 左侧强调线 | 未完成规则开启时始终使用自定义未完成色，不受底色优先级影响 |
| 类型图标 | 以日历/闪电形状区分类型，悬停显示名称；类型配色开启时使用对应颜色 |
| 关联图标 | 关联配色开启时使用组颜色，已完成任务也可辨认关联身份 |
| 拖拽提示 | 拖拽放置边框与嵌套提示优先于静态任务样式 |

同一任务在不同角色、不同卡片中的关联副本以共享标识选取固定颜色，移动、排序、修改文字及重载不改变选色。修改关联配色盘会同时更新所有对应副本。配色盘只有有限颜色，不同关联组可能同色；判断是否关联应以关联图标及同步关系为准，不能仅凭颜色。

普通待办卡片也可修改任务类型；本设置窗口只控制周计划表中的卡片。表格内尚未转换为卡片的旧文字单元格可通过右键插入待办卡片后使用这些功能。

类型以任务行尾的 `<!--apex-task-type:planned-->` / `<!--apex-task-type:temporary-->` 保存，和提醒、折叠、日记及关联标记兼容。类型随任务一起移动、复制、加密和解密；颜色设置保存在插件 `data.json` 的 `tableTaskStyles` 中，不写入周记正文。日历和历史任务扫描会剥离类型标记，不把它显示为任务文字。

实现分为三个模块：`src/task-metadata.ts` 定义类型及标记解析；`src/task-presentation.ts` 校验配置并以纯函数计算显示优先级；`src/task-presentation-ui.ts` 提供类型图标、设置窗口及 DOM 样式适配。渲染器通过回调获取配置，类型变更走现有同步引擎。设置保存只更新已有元素的样式，不重新载入笔记，不改变编辑、滚动、折叠或加密分区状态。增加新的显示场景时，应扩展样式策略及其组合测试。

回归：`npm run test:task-presentation` 覆盖优先级组合、配置校验、元数据、关联类型同步、重载和任务扫描；完整 `npm test` 包含这些检查及加密回归。应用内脚本 `scripts/test-task-presentation-ui-inapp.js` 使用内存合成任务验证菜单、同色、完成切换、设置预览与保存，并核对真实笔记哈希。

## 移动任务

直接拖动任务到当前周计划表另一单元格的待办卡片会移动任务；按住 Ctrl 拖拽并松开鼠标，则创建关联副本，来源卡片保留原任务。以松开鼠标时是否按住 Ctrl 为准，拖动途中可以按下或松开 Ctrl 切换复制/移动。副本的子任务、完成状态、提醒和日记关联完整保留；后续通过卡片界面编辑任意关联位置，其他关联位置同步更新。

支持以下放置位置：
- 空白列表区域：移到目标卡片末尾。
- 目标任务上方或下方：插入到相应位置。
- 目标任务中间：成为它的子任务。

任务的完成状态、所有子任务、提醒和日记关联一起保留。表格间、不同周工作台之间的拖放不会移动任务。

删除行或列时，原卡片仍保存在表格下方「未放置的卡片」区域。右键空白单元格，选择「放入卡片」可重新放置。删除卡片本身会沿用 Apex 原有的删除确认。

## 日记关联与跳转

点击任务旁的链接图标：
- 「选择已有日记文件」：在笔记库文件选择器里选择日记，不依赖核心日记插件。
- 「关联所选日期」：按核心「日记」插件配置关联对应日期；文件不存在时使用配置的模板创建，需要启用核心日记插件。
- 已有关联时可以取消关联。

关联后点击书本图标，直接打开对应日记。关联只保存日记路径，不会把任务复制进日记，也不提供任务状态双向同步。卡片原有的「保存到日记」功能仍是单独的任务导出操作。

日记文件被移动或重命名后，需要重新关联。文件不存在时跳转会提示，不会创建空白文件。

## 保存格式与兼容

表格单元格保存卡片 ID 标记，标准 Markdown 任务卡片保存在同一表格分区下方。日记路径作为任务行尾的编码元数据保存。无需额外数据库；普通和加密工作台都沿用现有保存通道。

旧表格不会自动批量改写，用户插入卡片时才转换对应单元格。使用旧版插件重新保存新版表格可能丢失卡片，请保留新版插件。


## 关联副本同步

- 仅新版 Ctrl 拖拽创建的关联副本会同步；旧的独立副本不会按相同文字自动合并。
- 同步范围为当前周计划表：文字、完成状态、提醒、日记关联、子任务的新增、编辑、删除和内部结构。
- 每处的卡片位置、顶层任务顺序、展开/折叠独立；删除当前位置的整棵任务树或卡片不会删除其他位置。
- 移出子任务会同步移除关联父任务中的该子任务，拖出的任务及其后代仍保留。不能将任务嵌套到自己、关联副本或关联后代之下。
- 任务旁的关联图标表示已建立同步关系。点击后选择「解除当前位置的任务树关联」，当前任务树成为独立副本，其他位置仍保持关联。若从子任务操作，会解除其所属关联任务树在当前位置的关联，避免父任务下次同步时重新带回关联。
- 关联信息保存在 Markdown 中，普通周记和加密周记均支持，关闭或重载后仍有效。不同周记、不同表格即使带有相同标识也不会互相同步。
- 第一版同步入口为卡片界面；直接手改 Markdown 不会主动合并其他副本。日记关联仍是文件跳转关系，不会与日记正文双向同步。
