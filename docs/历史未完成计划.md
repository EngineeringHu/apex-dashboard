# 历史未完成计划

历史未完成计划使用普通数据视图分区，由 Apex 的 DQL 引擎执行可编辑查询。点击分区设置即可修改 WHERE、SORT、GROUP BY、LIMIT 等语句，无需第三方 Dataview 插件。

默认查询：

```dql
TASK
FROM "周记"
WHERE dashboard AND file.folder = "周记"
WHERE !completed AND weekStart
WHERE weekStart <= this.weekStart AND weekStart <= date("sow")
WHERE file.path != this.file.path
SORT weekStart DESC, file.name ASC
GROUP BY file.link
```

this 指当前工作台；weekStart 是源周记的完整周起始日期，日期格式 YYYY-MM-DD。Apex 的 date("sow") 采用周日作为本周起点。默认包含同周其他工作台及更早周记的未完成任务，排除当前文件和未来周记；同日起始的多篇周记不会因日期相同而遗漏。来源范围、历史界限、完成状态和分组均由 DQL 决定。可改用 WHERE completed 查看已完成任务，或修改 SORT/LIMIT。

数据视图提供通用配置：任务只读、关联任务去重、点击来源打开普通笔记或 Apex 工作台。历史查询默认开启只读和去重，点击任务正文进入源周记工作台。关联任务即使在可编辑查询中也不能逐行勾选，需到原工作台编辑以保持同步。

任务查询字段包括 text、completed、due、priority，以及 Apex 扩展字段 syncId、syncKey、section、card、dailyNote。去重仅合并同一文件同一分区的关联任务，在筛选后、分组和限量前执行。旧表格里的显式复选任务可查询，但仅能到源文件编辑。普通说明文字不会作为任务。

工作台跳转模式在加密开启、转换中或临时解密会话期间停止读取。模板、隐藏目录和临时解密目录不会混入该模式。点击刷新重新查询，或重新打开工作台。

新建默认名称：2026年第N周-10月11号。跨年时使用周起始日的年份；例如 2027-01-01 对应 2026 年 12 月 27 日。序号保持原有文件计数规则。新文件记录 weekStart，后续编辑和加密转换保留该字段。

旧专用配置在加载时兼容为标准 DQL，保存后移除 weeklyHistory 标记。模板更新命令“周计划：为新建看板模板添加历史未完成计划”可升级加密模板，保留原密码、附件和正文并备份。再次执行不会重置用户自定义的查询。
