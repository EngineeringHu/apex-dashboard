# 历史未完成计划

历史未完成计划使用普通数据视图分区，由 Apex 的 DQL 引擎执行可编辑查询。点击分区设置即可修改 WHERE、SORT、GROUP BY、LIMIT 等语句，无需第三方 Dataview 插件。

默认查询：

```dql
TASK
FROM "周记"
WHERE dashboard AND file.folder = "周记"
WHERE !completed AND weekStart
WHERE weekStart <= this.weekStart AND weekStart <= date("sow")
WHERE file.path != this.file.path
SORT weekStart DESC, file.name ASC
GROUP BY file.link
```

this 指当前工作台；weekStart 是源周记的完整周起始日期，日期格式 YYYY-MM-DD。Apex 的 date("sow") 采用周日作为本周起点。默认包含同周其他工作台及更早周记的所有非完成任务（未完成、延迟、作废），排除已完成任务、当前文件和未来周记；同日起始的多篇周记不会因日期相同而遗漏。来源范围、历史界限、完成状态和分组均由 DQL 决定。可改用 WHERE completed 查看已完成任务，或修改 SORT/LIMIT。

## 状态和类型筛选

历史分区顶部及分区设置均提供多选筛选：

- 任务状态：未完成、已延迟、已作废、已完成。历史默认选中前三项。
- 任务类型：计划任务、临时任务；默认全部选中，无类型标记的旧任务视为计划任务。
- 同一组内取并集，两组之间取交集，例如只选「已延迟 + 临时任务」。取消某一组的所有选项会显示空结果，筛选入口仍保留。
- 筛选与 DQL 查询条件同时生效；要查看已完成任务，需要勾选「已完成」并调整默认查询的 `!completed` 条件。

筛选保存于当前分区的 `dataview.taskFilter`，在模板中设置后，新周记会继承；已创建的周记保留各自设置。旧内置历史查询自动采用新默认，无需重写模板；自定义查询文本不会被覆盖。状态与类型筛选在去重、分组及 LIMIT 之前执行。

列表通过状态图标区分未完成、延迟、作废，类型继续用日历/闪电小图标并提供悬停提示。作废任务保留删除线。点击正文进入来源工作台编辑。

数据视图提供通用配置：任务只读、关联任务去重、点击来源打开普通笔记或 Apex 工作台。历史查询默认开启只读和去重，点击任务正文进入源周记工作台。关联任务即使在可编辑查询中也不能逐行勾选，需到原工作台编辑以保持同步。

任务查询字段包括 text、completed、status、taskType、due、priority，以及 Apex 扩展字段 syncId、syncKey、section、card、dailyNote。`status` 值为 `pending` / `deferred` / `cancelled` / `completed`，`taskType` 值为 `planned` / `temporary`。例如 `WHERE status = "deferred" AND taskType = "temporary"`。作废任务的 `completed` 为 false。去重仅合并同一文件同一分区的关联任务，在筛选后、分组和限量前执行。旧表格里的显式复选任务可查询，但仅能到源文件编辑。普通说明文字不会作为任务。

工作台跳转模式在加密开启、转换中或临时解密会话期间停止读取。模板、隐藏目录和临时解密目录不会混入该模式。点击刷新重新查询，或重新打开工作台。

新建默认名称：2026年第N周-10月11号。跨年时使用周起始日的年份；例如 2027-01-01 对应 2026 年 12 月 27 日。序号保持原有文件计数规则。新文件记录 weekStart，后续编辑和加密转换保留该字段。

旧专用配置在加载时兼容为标准 DQL，保存后移除 weeklyHistory 标记。模板更新命令“周计划：为新建看板模板添加历史未完成计划”可升级加密模板，保留原密码、附件和正文并备份。再次执行不会重置用户自定义的查询。
